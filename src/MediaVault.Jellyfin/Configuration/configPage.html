Media Vault Cloud Catalogue

Cloud-backed Media Vault films are browsed here without being represented as fake local media files.

Remote Cloudflare Example (use this): "https://media-vault-cloud-catalogue.parkerjack931.workers.dev/"
Local Example: "http://192.168.1.1:3001/api/jellyfin/catalogue"

GPhotosDL

GPhotosDL handles Google Photos authentication and downloads. The plugin only connects to its HTTP API.

This is the link to the GPhotosDL server URL. You need that application running for the connection to work.

Download Directories

These are the final paths on the Jellyfin server where GPhotosDL will place downloaded media.

These directories need to be the same as your local libraries' drectories in order for Jellyfin to know where to save the media to.

Catalogue Refresh

Used for requests between Jellyfin and the catalogue/GPhotosDL servers.
After this delay the plugin checks the GPhotosDL job. Jellyfin is refreshed automatically when the download completes, so partially-downloaded MKV files are not added to the library.

Playback Startup Buffer

Media Vault starts the Google Photos download immediately, then exposes the real local MKV to Jellyfin once enough data has buffered. This prevents FFmpeg from reaching the current end of a growing file and stopping playback after a few seconds.

How long the initial Play request may wait for the playback buffer before Jellyfin receives no source. The download continues in the background.
Default 5%. The plugin also applies the minimum and maximum buffer limits below.
The default 0.5GB range is deliberately chosen to match the observed behaviour where playback becomes reliable after a few GB have downloaded.
